# guides — 常设制度与说明

## 职责

放**跨需求复用**的工作规则、系统说明和环境记录。这里的内容长期有效，不随单个需求产生或消失；一次性交付物放 `../deliverables/`。

## 文件索引

| 文件 | 作用 |
| --- | --- |
| `agent-system.md` | 角色、五阶段门禁、10 个 skill、文件流转、同步机制的总说明（建议先读） |
| `conventions.md` | 工作约定：一手来源、脚手架、模板同步、数据库迁移、命名等硬规则 |
| `server-module-architecture.md` | Server 目录模板、构件放置、接口设计、DTO 与 OpenAPI 契约规范 |
| `pitfalls.md` | 踩坑记录，按「现象 / 原因 / 解决」记录本机与仓库的实际问题 |
| `credentials.md` | 本地开发默认凭据与生产必改清单 |

## 关联

- **上游**：规则源头在 `../../agents/` 与 `../../skills/`；这里写的是它们的索引与解释，改规则要先改源头。
- **下游**：`../deliverables/<slug>/` 的 PRD 与技术方案会引用这里的约定。
- **总入口**：`../README.md` 的文档地图。

## 同步要求

新增、删除、改名文件或职责发生变化时，更新本文件与 `../README.md` 的文档地图；若涉及硬规则，同步 `../../agents/` 与 `../../skills/` 中的对应条款。
