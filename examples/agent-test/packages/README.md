# packages

## 职责

跨应用共享代码。`apps/*` 只放端上专属的东西（页面、路由、状态），凡是两个及以上应用要用的，都下沉到这里。

## 目录

| 目录 | 作用 | 形态 |
| --- | --- | --- |
| `shared/` | 常量、工具函数、类型 | TS 源码，Vite 直接消费，无构建产物 |
| `api/` | 接口层：类型、SDK、错误处理 | 同上，手写装配在 `config.ts` |

## 注意事项

- 两个包都以 TS 源码形式被消费，`exports` 是白名单：新增子路径必须同时改 `package.json` 的 `exports`，否则引用方解析不到。
- 不引入宿主环境依赖（`react`、`fetch`、`window`），否则小程序 / App 端无法复用。
- 每个包的 `src/` 都要有 README，新增目录同样要补。
